An end-to-end system for spotting fraudulent blockchain transactions as they happen.

- **Ingestion and pipelines:** Azure Event Hub, Data Factory, and Synapse for real-time analytics
- **Modeling:** logistic regression on graph-based features of the transaction network
- **Delivery:** Azure Function Apps push results into Power BI dashboards, alongside simulations generated with OpenAI
